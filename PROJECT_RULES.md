# BizGuard AI — Project Rules

## 1. Project Architecture

Use MVC-style architecture.

Keep frontend and backend clearly separated.

## 2. MVP First

Build only the features defined for the BizGuard AI MVP.

Do not add unnecessary features.

## 3. AI Workflow

The core AI workflow is:

Analyze → Detect → Explain → Recommend

Keep these stages logically separated.

## 4. Code Quality

Keep the code modular, simple, readable, and maintainable.

Avoid unnecessary complexity.

## 5. Frontend

Frontend should contain only UI and frontend-related logic.

Do not put backend business logic inside the frontend.

## 6. Backend

Backend should handle:

- API endpoints
- Business logic
- Data processing
- AI workflow
- Database/data access

## 7. Development Phases

Implement the project step by step.

Do not build the complete application at once.

Only implement the feature requested in the current development step.

## 8. File Structure

Keep files organized according to their responsibility.

Do not create duplicate or unnecessary files.

## 9. Changes

Before making major architectural changes, explain the reason first.

Do not modify unrelated parts of the project.

## 10. Hackathon Focus

Prioritize:

- Working MVP
- Clear user experience
- Reliable business insights
- Explainable AI recommendations
- Clean architecture
- Easy demonstration
